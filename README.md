# HIT137 Assignment 3 - Spot the Difference Game

GitHub Repository: https://github.com/AveryDoan/Assignment-3---Software-Now

## Project Purpose

This repository is a group assignment scaffold for a desktop Spot the Difference game built with Python, Tkinter, and OpenCV.

The goal is to keep the project structure, ownership, and submission files ready before implementation begins.

## File Ownership Plan

- `main.py` - Avery: application entry point and startup flow
- `game_controller.py` - Avery: coordinates GUI, game logic, and image processing
- `image_processor.py` - Max: OpenCV image loading, cloning, difference generation, and image marking
- `game_logic.py` - Alvi: click validation, mistakes, scoring, reveal state, and round rules
- `gui.py` - Jane: Tkinter window, layout, controls, dialogs, and image display

## Team Responsibilities

- Avery - project architecture, integration, OOP design, final submission
- Max - OpenCV image processing, random difference generation, scaling
- Jane - Tkinter GUI, layout, buttons, counters, dialogs
- Alvi - click detection, scoring, mistakes, reveal logic, reset behavior

## Submission Files

- `github_link.txt` - repository link for submission
- Python source files - implementation files for the assignment
- `assets/` - images or supporting files used during testing

## Status

This scaffold contains only structure and planning notes. No implementation code has been added yet.
